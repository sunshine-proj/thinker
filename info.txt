1. Linting
I used oxlint (.oxlintrc.json, npm run lint) instead of ESLint. The project uses the native TypeScript 7 compiler, and typescript-eslint supports only TypeScript below 6.1. I also added npm run typecheck. The README notes this and says to revisit it once typescript-eslint supports TypeScript 7.
The type check and lint are clean.

2. Shared components
RangeControl replaces two duplicate copies, and ToggleControl is new. Both are in src/components/common/.
The slider label is now a proper <label>, which fixed two accessibility lint errors.
useSimulationCanvas.ts now owns the engine lifecycle, throttled React updates, canvas resizing and cleanup. The electron lab page dropped about 80 lines because of it.
New GameProgressBar and GameHint components are used by both games.
I renamed the projectile-* CSS classes that were really generic to game-*.

3. Progress persistence
Results are saved in IndexedDB, with an in-memory fallback when IndexedDB isn't available. The code is in src/services/storage/, with a Zustand store in src/store/progressStore.ts.
If storage fails, play continues and an error is shown. The store also avoids counting a result twice when saving happens before loading finishes.
Both games save a result on completion. The Profile page now shows best scores, and Physics Worlds marks completed games.
Syncing with Supabase is not done.

4. Balance Challenge
The torque model is torque.ts. It computes torque (τ = m g d), net torque, support force, and solves for a balancing position or mass.
There are three rounds, one per difficulty:
Classic seesaw: find the position for a 2 kg block.
Three weights: find the mass to place at a fixed spot.
Heavy beam: an off-centre beam counts as a weight at its centre.
The player predicts first, then sets a control and releases the lever. The lever stays level until released.
Scoring is 60 for accuracy, 20 for the prediction and 20 for the attempt count (20 on the first release, 10 on the second, then none), so speed doesn't count. Tests check that one control step off still passes and two steps off fails.
The tilt shown on release shows the direction and relative size of the net torque, not a simulation of the lever's motion. This is documented in the game's assumptions.
