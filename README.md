
# Physics Playground

An interactive educational PWA for learning physics through games, experiments, and scientific exploration.

## Getting Started

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Run the checks and production build with:

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm run verify:pwa   # after a build: checks manifest, icons, service worker and offline precache
```

Linting uses [oxlint](https://oxc.rs/docs/guide/usage/linter) (`.oxlintrc.json`) rather than ESLint: the project uses the native TypeScript 7 compiler, which typescript-eslint does not support yet. Revisit this when typescript-eslint supports TypeScript 7.

## Architecture Notes

- Shared UI controls live in `src/components/common` (`RangeControl`, `ToggleControl`); reusable game pieces in `src/game-engine/components`; canvas simulations use the `useSimulationCanvas` hook in `src/hooks`.
- Learner progress is stored locally: `src/services/storage/progressRepository.ts` (IndexedDB, with an in-memory fallback), exposed through the Zustand store in `src/store/progressStore.ts`. Synchronization with Supabase is not implemented yet.
- Storage is IndexedDB schema v2 (game results, saved experiments, achievements, in-progress game sessions); upgrades from v1 keep existing data. Games resume through `useGameSession`; achievements, levels and challenges are pure functions in `src/game-engine/progression`.
- Experiments use shared measurements (`src/simulation/measurements`), a saved-experiments panel with comparison, and generated result explanations (`electronExperiment.ts`).
- PWA: `vite-plugin-pwa` (generateSW, update prompt, app-shell precache, offline navigation fallback). Icons are generated by `tools/generate-icons.py`. `src/services/sync` provides a reconnect-triggered sync manager, but no remote adapter is configured, so progress is local-only until Supabase is wired in.
- Playable content is registered in `src/data/games/gameCatalog.ts`, which drives the Physics Worlds page.
