
# Physics Playground

An interactive educational PWA for learning physics through games, experiments, and scientific exploration.

## Getting Started

Requires Node.js and npm.

```bash
npm install
npm run dev
```

Run the tests and production build with:

```bash
npm test
npm run build
```

## Initial Development Milestones
